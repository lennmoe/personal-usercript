# Personal Userscripts

A collection of userscripts for various websites.

## osu! Scripts

- **osu! BBCode copier.js** - Copy beatmap information in BBCode format
- **osu! Expert+.js** - Advanced features for osu!
- **osu! crop.js** - Crop tool for osu! screenshots
- **osu! my download.js** - Download manager for osu! content
- **osu! scores inspector.js** - Inspect and analyze osu! scores

## VNDB Scripts

- **VNDB Character Count.js** - Display character counts on VNDB
- **VNDB Official Links and Release Dates.js** - Show official links and release information
- **VNDB Score Graph.js** - Display score graphs for visual novels
- **VNDB Shearch CG.js** - Search for CGs on "hitomi.la" & "imhentai.xxx" & "e-hentai.org"

## Installation

1. Install a userscript manager like [Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/)
2. Click on a script file to view its source
3. Copy the script and create a new userscript in your manager
4. Paste the code and save

## Usage

Each script is designed for a specific website. Navigate to the corresponding website and the script will activate automatically.
